# ChemMan ↔ IFS Cloud Integration Plan

**Date:** 2025-10-23
**IFS Cloud Version:** 24R1
**ChemMan Version:** 2.0
**Integration Type:** REST API with OAuth 2.0

---

## 📋 Executive Summary

This document outlines the integration plan between ChemMan (hazardous substance tracking system) and IFS Cloud ERP. The integration will enable:
- **Bi-directional data sync** between ChemMan and IFS inventory system
- **Automatic hazard data enrichment** in IFS from ChemMan's CLP/SVHC databases
- **SDS document management** synced to IFS Document Management
- **Real-time location tracking** between both systems

## 🔑 Authentication Setup

### IFS Cloud OAuth 2.0 Configuration

IFS Cloud 24R1 uses **OAuth 2.0** with **Client Credentials** grant for service-to-service integration.

#### Step 1: Find Your OAuth Endpoints

Navigate to: `https://[YOUR-IFS-DOMAIN]/.well-known/openid-configuration`

This returns a JSON with all endpoints:
```json
{
  "token_endpoint": "https://[YOUR-IFS-DOMAIN]/auth/realms/[REALM]/protocol/openid-connect/token",
  "authorization_endpoint": "...",
  "issuer": "...",
  ...
}
```

#### Step 2: Create IAM Client in IFS Cloud

**Your IFS Administrator needs to:**

1. Log into IFS Cloud as Administrator
2. Navigate to: **Security** → **IAM Settings** → **IAM Clients**
3. Click **New** to create a new client
4. Configure:
   - **Client ID**: `chemman-integration` (or your choice)
   - **Client Type**: `Service User` (for non-interactive integration)
   - **Authentication Method**: `Client Credentials`
   - **Grant Types**: Enable `client_credentials`
   - **Scopes**: `openid microprofile-jwt`
   - **Access Type**: `Confidential`
5. Save and copy the **Client Secret** (shown only once!)

**Example IAM Client Configuration:**
```yaml
Client ID: chemman-integration
Client Secret: [Generated by IFS - copy this!]
Grant Type: client_credentials
Scopes: openid microprofile-jwt
Valid Redirect URIs: https://your-chemman-server/oauth/callback (optional)
```

#### Step 3: Test Authentication with Postman

Before coding, test OAuth flow:

1. Open Postman
2. Create new request
3. **Authorization** tab:
   - Type: `OAuth 2.0`
   - Grant Type: `Client Credentials`
   - Access Token URL: `https://[YOUR-IFS]/auth/realms/[REALM]/protocol/openid-connect/token`
   - Client ID: `chemman-integration`
   - Client Secret: `[from Step 2]`
   - Scope: `openid microprofile-jwt`
4. Click **Get New Access Token**
5. If successful, you'll receive an access token

## 📊 Data Mapping Strategy

### Substance Identification

How to match substances between ChemMan and IFS:

| ChemMan Field | IFS Field | Mapping Strategy |
|--------------|-----------|------------------|
| CAS Number | Custom Field: `CAS_NUMBER` | Primary identifier |
| EC Number | Custom Field: `EC_NUMBER` | Secondary identifier |
| Substance Name | `PartNo` or `Description` | Create naming convention |
| ChemMan ID | Custom Field: `CHEMMAN_ID` | Link back to ChemMan |

**Proposed Part Number Convention:**
```
CHEM-[CAS-NUMBER]
Example: CHEM-71-43-2 (Benzene)
```

### Location Mapping

| ChemMan Location | IFS Location | Notes |
|-----------------|--------------|-------|
| "Magazyn Główny" | Site: "SITE01", Location: "MAIN-01" | 1:1 mapping |
| "Laboratorium A" | Site: "SITE01", Location: "LAB-A-01" | Multiple ChemMan → 1 IFS possible |

### Custom Fields Needed in IFS

Ask your IFS admin to add these custom fields to **Inventory Part Master**:

1. `CHEMMAN_ID` (Integer) - Link to ChemMan substance ID
2. `CAS_NUMBER` (String, 50) - CAS registry number
3. `EC_NUMBER` (String, 50) - EC number
4. `IS_CMR` (Boolean) - CMR classification flag
5. `IS_SVHC` (Boolean) - SVHC flag
6. `H_PHRASES` (String, 500) - Hazard phrases (comma-separated)
7. `HAZARD_CLASS` (String, 200) - Hazard classification
8. `SDS_FILE_ID` (String, 100) - Reference to SDS document in IFS

## 🔄 Integration Scenarios

### Scenario 1: New Substance in ChemMan → Create in IFS

**User Action:** User adds new substance in ChemMan

**ChemMan Process:**
1. User searches CLP database, finds "Benzene"
2. ChemMan retrieves hazard data (CMR: Yes, H-phrases: H225, H350, H372, etc.)
3. User uploads SDS PDF
4. User clicks **"Sync to IFS"** button

**Integration Flow:**
```python
1. ChemMan checks if substance exists in IFS (by CAS number)
2. If not exists:
   a. Create Part in IFS:
      POST /InventoryPart.svc/InventoryPartSet
      {
        "PartNo": "CHEM-71-43-2",
        "Description": "Benzene",
        "UnitMeas": "L",
        "CAS_NUMBER": "71-43-2",
        "EC_NUMBER": "200-753-7",
        "IS_CMR": true,
        "IS_SVHC": false,
        "H_PHRASES": "H225, H350, H372, H315, H319, H304, H336, H340, H373",
        "HAZARD_CLASS": "Carc. 1A, Muta. 1B, ..."
      }

   b. Upload SDS to IFS Document Management:
      POST /DocumentText.svc/DocumentTextSet
      {
        "DocClass": "SAFETY_DATA_SHEET",
        "DocNo": "SDS-CHEM-71-43-2",
        "DocSheet": "1",
        "DocRev": "1",
        "FileName": "Benzene_SDS.pdf",
        "FileData": "[Base64 encoded PDF]"
      }

   c. Link document to Part:
      POST /InventoryPartDocuments.svc/...
      Link SDS document to inventory part

   d. Update ChemMan:
      - Store IFS Part ID
      - Mark as "Synced"
      - Log action in audit log
```

### Scenario 2: New Purchase Order in IFS → Notify ChemMan

**IFS Action:** Chemical received via Purchase Order

**Integration Flow:**
```python
1. IFS webhook/scheduled check for new goods receipts
2. ChemMan receives notification of new part:
   {
     "PartNo": "CHEM-108-88-3",
     "Description": "Toluene",
     "Quantity": 25,
     "Location": "MAIN-WAREHOUSE-A01"
   }
3. ChemMan checks if substance exists (by Part No or CAS)
4. If exists:
   - Update location
   - Log receipt
5. If NOT exists:
   - Alert user: "New chemical received in IFS - needs hazard data"
   - User completes hazard data in ChemMan
   - Sync hazard data back to IFS
```

### Scenario 3: Move Substance in ChemMan → Update IFS Location

**User Action:** User moves substance between locations

**Integration Flow:**
```python
1. User moves "Benzene" from "Lab A" to "Warehouse B" in ChemMan
2. ChemMan API call to IFS:
   POST /InventoryTransaction.svc/TransactionSet
   {
     "PartNo": "CHEM-71-43-2",
     "FromLocation": "LAB-A-01",
     "ToLocation": "WAREHOUSE-B-02",
     "Quantity": 1,
     "TransactionCode": "INTSHIP"
   }
3. IFS records transaction
4. Both systems updated
```

### Sample OAuth Client (`ifs_integration/auth.py`)

```python
import requests
from datetime import datetime, timedelta
from flask import current_app

class IFSAuthClient:
    """OAuth 2.0 authentication for IFS Cloud"""

    def __init__(self):
        self.client_id = current_app.config.get('IFS_CLIENT_ID')
        self.client_secret = current_app.config.get('IFS_CLIENT_SECRET')
        self.token_url = current_app.config.get('IFS_TOKEN_URL')
        self.scope = 'openid microprofile-jwt'

        self.access_token = None
        self.token_expires = None

    def get_access_token(self):
        """Get valid access token (refresh if expired)"""
        if self.access_token and self.token_expires > datetime.now():
            return self.access_token

        # Request new token
        response = requests.post(
            self.token_url,
            data={
                'grant_type': 'client_credentials',
                'client_id': self.client_id,
                'client_secret': self.client_secret,
                'scope': self.scope
            }
        )

        if response.status_code == 200:
            data = response.json()
            self.access_token = data['access_token']
            expires_in = data.get('expires_in', 3600)
            self.token_expires = datetime.now() + timedelta(seconds=expires_in - 60)
            return self.access_token
        else:
            raise Exception(f"Failed to get access token: {response.text}")
```

### Sample IFS API Client (`ifs_integration/client.py`)

```python
import requests
from .auth import IFSAuthClient

class IFSClient:
    """REST API client for IFS Cloud"""

    def __init__(self):
        self.auth = IFSAuthClient()
        self.base_url = current_app.config.get('IFS_API_BASE_URL')
        # e.g., "https://your-ifs.cloud/main/ifsapplications/projection/v1"

    def _headers(self):
        """Get headers with current access token"""
        return {
            'Authorization': f'Bearer {self.auth.get_access_token()}',
            'Content-Type': 'application/json',
            'Accept': 'application/json'
        }

    def get_inventory_part(self, part_no):
        """Get inventory part by part number"""
        url = f"{self.base_url}/InventoryPart.svc/InventoryPartSet('{part_no}')"
        response = requests.get(url, headers=self._headers())
        return response.json() if response.status_code == 200 else None

    def create_inventory_part(self, part_data):
        """Create new inventory part"""
        url = f"{self.base_url}/InventoryPart.svc/InventoryPartSet"
        response = requests.post(url, json=part_data, headers=self._headers())
        return response.json() if response.status_code == 201 else None

    def update_inventory_part(self, part_no, part_data):
        """Update existing inventory part"""
        url = f"{self.base_url}/InventoryPart.svc/InventoryPartSet('{part_no}')"
        response = requests.patch(url, json=part_data, headers=self._headers())
        return response.status_code == 200

    def upload_document(self, doc_data, file_content):
        """Upload document to IFS"""
```
